# Безопасность

## Что нельзя прикладывать к issue

- `desktop.log`, `fr_drv_ng.log` и другие журналы кассы целиком;
- `vk-token.dat` и значения `BIFIT_REPORT_VK_TOKEN`;
- каталог `C:\ProgramData\BifitReport`;
- банковские слипы, номера карт, телефоны, e-mail, ИНН и идентификаторы устройств.

Для диагностики достаточно версии приложения, обезличенного фрагмента `status.json`, кода ошибки доставки и времени события.

## Модель доступа

Агенту нужен только доступ на чтение к журналу БИФИТ и запись в собственный каталог состояния. Он не должен получать права на изменение каталога данных кассы и не должен открывать `data.mv.db`.

Токен VK шифруется Windows DPAPI в области `LocalMachine`. Защита дополняется ACL каталога: чтение разрешается только `SYSTEM`, локальным администраторам и пользователю, который сохранил токен.
